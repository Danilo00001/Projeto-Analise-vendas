# Análise Estatística de Vendas

## Sobre o projeto

Este projeto realiza uma análise estatística de uma base de dados de vendas, utilizando Python para investigar preços, descontos e categorias de produtos.

## Tecnologias utilizadas

* Python
* Pandas
* Matplotlib
* Plotly

## Análises realizadas

* Cálculo da média e mediana dos preços por categoria.
* Comparação entre média e mediana.
* Identificação da categoria com maior desvio padrão.
* Visualização da distribuição dos preços por meio de boxplot.
* Identificação de valores atípicos (*outliers*).
* Gráfico de barras da média de desconto por categoria.
* Visualização interativa da média de desconto por categoria e marca.

## Como executar

1. Instale as bibliotecas necessárias com `pip install pandas matplotlib plotly`.
2. Coloque o arquivo `dados_vendas.csv` na mesma pasta do código.
3. Execute `main.py` no Python.

## Arquivos

* `main.py`: código-fonte da análise.
* `dados_vendas.csv`: base de dados utilizada.
* `graficos/`: imagens dos gráficos, quando incluídas.
